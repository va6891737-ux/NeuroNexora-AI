# 🧠 NeuroNexora AI

## Human-Centric Intelligent Decision Platform

NeuroNexora AI is an AI-assisted decision-support platform that helps users analyze personal goals, compare multiple options, understand trade-offs, and receive explainable recommendations.

### 🚀 Key Features

- 👤 User Profile & Personalization
- 🔍 AI Decision Analysis
- 📊 Option Comparison
- 💡 Explainable AI (XAI)
- 📈 Compatibility Scoring
- 💬 AI Chat
- 🧠 Final Decision-Support Summary

### 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- OpenAI API
- Browser LocalStorage

### 🎯 Objective

To provide personalized and explainable AI-assisted information that supports users in making informed decisions.

### 📌 Note

The compatibility scores are AI-assisted indicative scores and should not be treated as guaranteed predictions.
